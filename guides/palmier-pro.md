# Palmier Pro: видеоредактор, которым управляет агент

**[palmierai.pro](https://palmierai.pro/)** · macOS · платный

Обычный видеоредактор — это чёрный ящик для агента. Он видит файлы на входе и файл на
выходе, а всё, что между, происходит руками в чужом интерфейсе. Palmier Pro устроен иначе:
он поднимает локальный MCP-сервер и отдаёт наружу сам таймлайн.

## Что это меняет

Агент получает не «папку с клипами», а структуру проекта: какие клипы на каких дорожках,
какой они длительности, какими промптами были сгенерированы, какие у них референсы.
Дальше он работает с этим как с данными — читает таймлайн, добавляет клипы, подрезает
сегменты, меняет порядок кадров, генерирует новый материал по промпту и перегенерирует
уже сделанный, уточнив формулировку.

Разница не в том, что «стало на пару кликов меньше». Разница в том, что монтаж попадает
в тот же разговор, что и всё остальное. В одном чате можно найти B-roll через Coverr,
сгенерировать озвучку, посчитать тайминги — и тут же положить это на дорожку, не
экспортируя ничего между шагами. Контекст не разваливается на границе инструментов.

## Как подключается

Сервер живёт на `http://127.0.0.1:19789/mcp` — локально, по HTTP. К нему цепляются
Claude Code, Claude Desktop, Cursor и Codex.

Для Claude Code:

```bash
claude mcp add --transport http palmier http://127.0.0.1:19789/mcp
```

Под капотом сервер работает мостом между протоколом MCP и внутренним исполнителем
команд редактора — тем самым, который и вносит изменения в проект. То есть агент ходит
не в обход приложения, а через его же механику правок.

## Где границы

**Только macOS и только платно.** Если нужен кроссплатформенный или бесплатный вариант —
это не он; собирай через [Remotion](../catalog/assembly.md) программно.

**Редактор должен быть запущен.** Сервер локальный: приложение закрыто — MCP недоступен,
агент вместо таймлайна увидит ошибку соединения.

**Порт открыт на машине.** `127.0.0.1` слушает только локально, наружу не торчит, но
любой процесс на той же машине может к нему обратиться. Для рабочего ноутбука это
нормально, для общей машины — стоит подумать.

## Когда брать не его

Если ролик собирается по одному и тому же шаблону раз за разом — Remotion выигрывает:
композиция описана кодом, диффы читаются в ревью, рендер воспроизводим до кадра.
Palmier Pro сильнее там, где монтаж каждый раз разный и решения принимаются по ходу.
