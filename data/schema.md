# Схема данных

Каталог живёт в двух файлах. Всё остальное — `README.md` и всё в `catalog/` — генерируется
из них скриптом `scripts/build.py` и правится только через YAML.

## `tools.yaml`

### `meta`
Заголовок каталога, подзаголовок и адрес репозитория. Меняется редко.

### `categories`
Порядок в этом списке задаёт порядок разделов в README.

| Поле | Обяз. | Что это |
|---|---|---|
| `id` | да | Короткий латинский идентификатор. Из него получается имя файла `catalog/<id>.md` и якорь в README. |
| `name` | да | Название раздела по-русски. |
| `emoji` | да | Один эмодзи для визуального якоря. |
| `blurb` | да | Одна фраза: что за инструменты внутри и когда за ними идти. |

### `tools`

| Поле | Обяз. | Значения | Что это |
|---|---|---|---|
| `id` | да | | Уникальный. На него ссылается `routing.yaml`. |
| `name` | да | | Как инструмент называет себя сам. |
| `category` | да | id из `categories` | |
| `kind` | да | `app` `mcp` `library` `api` `service` `model` `cli` `spec` `format` `reference` | Что это физически. |
| `pricing` | да | `free` `freemium` `paid` `oss` | |
| `url` | да | | Главная ссылка. |
| `tagline` | да | | **Одна строка.** Не «что это такое вообще», а зачем брать именно его. Попадает в таблицу README. |
| `status` | да | `verified` `listed` | `verified` — гоняли руками на реальных проектах, в README получает ⭐. `listed` — внесён по результатам изучения, но вживую не проверялся. Не ставь `verified` авансом: вся ценность звёздочки в том, что ей можно верить. |
| `agent` | нет | `mcp` `api` `cli` `native` `none` | Как до инструмента дотягивается агент. По умолчанию `none`. |
| `key` | нет | `none` `optional` `required` | Нужен ли API-ключ. По умолчанию `none`. |
| `key_url` | нет | | Где этот ключ получают. |
| `install` | нет | | Одна команда установки. Попадает в `bash`-блок на странице категории. |
| `env` | нет | список | Имена переменных окружения. **Только имена. Никогда не значения.** |
| `docs` | нет | | Ссылка на документацию. |
| `repo` | нет | | Ссылка на исходники. |
| `platforms` | нет | список | Если инструмент работает не везде. |
| `tags` | нет | список | Для поиска по странице. |
| `guide` | нет | путь от корня репозитория | Ссылка на разбор в `guides/`. Генератор падает, если файла нет. |
| `note` | нет | многострочный markdown | Подробности: подводные камни, лимиты, чем отличается от соседа по таблице. Показывается только на странице категории, в README не попадает. |

## `routing.yaml`

Таблица «задача → инструмент», с которой начинается README. Это главная страница
каталога по смыслу: человек приходит с задачей, а не с названием инструмента.

```yaml
routing:
  - group: "Название группы задач"
    rows:
      - task: "Что человек хочет сделать"
        tools: [id, id, id]     # порядок = порядок предпочтения
        note: "Необязательная подсказка, чем именно выбирать"
```

`tools` — это id из `tools.yaml`. Генератор разворачивает их в ссылки и **падает с ошибкой**,
если id не существует, поэтому таблица не может протухнуть незаметно.
